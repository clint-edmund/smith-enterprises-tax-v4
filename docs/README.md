# Atlas Tax Management Platform

## Overview

Atlas is a modern tax practice management platform designed to streamline the entire client lifecycle, from intake through filing, review, document management, and client communication.

This repository contains:

- React + TypeScript frontend
- Supabase backend
- Secure Vault architecture
- Client Portal
- Organizer Framework
- Document Management
- Review Workflow
- Local Development Platform

---

## Development Philosophy

Atlas follows a local-first development model.

All new features are:

1. Developed locally
2. Tested locally
3. Validated
4. Committed to Git
5. Deployed

Production is never used for feature development.
