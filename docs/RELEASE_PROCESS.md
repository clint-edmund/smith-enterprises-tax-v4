# Atlas Release Process

## Development

Developer creates a feature branch.

↓

Push to GitHub.

↓

Create Pull Request into develop.

↓

GitHub Actions execute.

↓

Preview deployment is generated.

↓

Customer validates.

↓

Pull Request into main.

↓

Production deployment executes.

---

Production releases are tagged using Semantic Versioning.

Example:

v1.0.0

v1.1.0

v2.0.0
